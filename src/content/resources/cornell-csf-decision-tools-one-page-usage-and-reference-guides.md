The Climate Smart Farming decision support tools are used when making informed decisions about production systems based on location-specific climate data, weather forecasts, and future outlooks. These [One-Page Reference Guides to the CSF Tools](http://climatesmartfarming.org/wp-content/uploads/2019/01/csf-tools-one-page-guides.pdf) provide the short steps and graphics to start using these tools quickly.
