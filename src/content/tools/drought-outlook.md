The Climate Prediction Center's (CPC) [Seasonal Drought Outlook](http://www.cpc.ncep.noaa.gov/products/expert_assessment/sdo_summary.php) depicts large-scale drought trends over the next three months based on subjectively derived probabilities guided by short- and long-range statistical and dynamical forecasts. Use caution for applications that can be affected by short-lived events. For a detailed regional discussion and list of tools used to create this outlook, please view the [Seasonal Drought Outlook Discussion](http://www.cpc.ncep.noaa.gov/products/expert_assessment/sdo_discussion.php). This outlook is issued monthly on the third Thursday of each month.
